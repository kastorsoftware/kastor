# Kastor

[<kbd>🇬🇧 English</kbd>](README.md)

Десктопное приложение для работы с Telegram-аккаунтами. Интерфейс написан на React, нативная часть — на Rust/Tauri.

> Проект распространяется по [The Unlicense](LICENSE): код можно использовать, изменять, публиковать и продавать без условий, в том числе без указания автора. Он предоставляется «как есть», без гарантий.

## Возможности

- импорт, авторизация и управление Telegram-аккаунтами;
- работа с прокси, их проверка и распределение по аккаунтам;
- проверка аккаунтов, конвертация сессий и массовые действия;
- инструменты для рассылок, парсинга, инвайтинга, автоответов, клонирования и других сценариев;
- локальное хранение данных в SQLite и очередь фоновых задач.

Используйте приложение законно и соблюдайте правила Telegram. Ответственность за используемые аккаунты лежит на вас.

## Разработка

Нужны Node.js, Rust и системные зависимости Tauri для Windows. Для сборки настоятельно рекомендуется Rust MSVC-тулчейн.

```bash
npm install
npm run tauri dev
```

Сборка фронтенда:

```bash
npm run build
```

Сборка десктопного приложения:

```bash
npm run tauri build
```

## Структура проекта

- `src/` — React-фронтенд;
- `src-tauri/` — Rust/Tauri backend и MTProto-клиент.
